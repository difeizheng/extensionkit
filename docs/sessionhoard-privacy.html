Session Hoard Privacy Policy

Last updated: 2026-11-02

What we store

Your saved sessions (tab titles and URLs) are stored only in your browser's local storage, on your machine, inside your browser profile. We operate no servers that receive your browsing data. The extension contains no analytics, no tracking, and no remote code.

What leaves your machine

In the version that is currently published (1.1.0), nothing leaves your machine. The free tier never contacts any server — there is no analytics, no telemetry, and no analytics-style background traffic.

The extension does request permission for a single host, your-license-server.example.com, because the optional Pro license feature is already built into the code. That host is a placeholder that has never been activated and does not resolve, so if you type a license key the request cannot connect: your sessions, your tab titles, your URLs, and the key itself are not actually transmitted anywhere.

Before the Pro tier is switched on we will remove that permission, and this page will be updated before any version that talks to a server is published. When that happens, activation requests will contain only the license key and a random device identifier — never your sessions, tab titles, URLs, or anything you browse.

Your data, your call

You can export everything to a readable JSON file, and delete everything, from the options page at any time. Uninstalling the extension removes it and its data entirely.

Changes

If this policy changes, the extension's store listing will be updated with a new "last updated" date. Material changes will be called out in the release notes.

Why this exists

Chrome killed its payment system in 2021. Since then, every developer monetizing an extension hand-rolls the same week of work: webhook signature verification, replay protection, offline grace periods, device management, activation UX. ExtensionKit is that week, done, documented, and covered by tests — so you ship your product instead.

What you get

💸 Stripe → license key, hands-off

One Payment Link + one webhook. Every payment automatically mints a human-friendly key (XXXX-XXXX-XXXX-XXXX, ambiguous chars removed).

✈️ Offline-first validation

Cached HMAC-signed tokens keep users licensed on planes and in tunnels. Silent revalidation, bounded revocation window.

📱 Device slots, self-serve

3 devices per key by default; users free slots themselves. No "please reset my license" emails.

🧩 Zero dependencies

The server is Node built-ins only — no npm install, no supply-chain audit. The extension is vanilla MV3 — no build step.

✅ Actually tested

13 end-to-end tests: activation limits, token forgery, webhook replay, admin auth, rate limiting. npm test and watch them pass.

Five minutes, running locally

git clone https://github.com/difeizheng/extensionkit.git
cd extensionkit/server
cp .env.example .env        # paste a generated LICENSE_SECRET
node src/index.js           # → http://localhost:8787  (no npm install)

Load the extension/ folder in Chrome, point it at your server, activate a test key. Full walkthrough in docs/getting-started.md.
